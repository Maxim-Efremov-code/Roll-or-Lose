# Roll or Lose

Roll or Lose is a fast-paced arcade game where you control a rolling ball: evade enemies and collect cubes.

## Features
- Sound effects and dynamic audio
- Camera switching between first-person and third-person views
- A pause menu

## Controls
- Movement: W/A/S/D or arrows
- Switch camera: Left Ctrl
- Pause: Tab
