# Roll or Lose

Roll or Lose is a fast-paced arcade game where you control a rolling ball: evade enemies and collect cubes.

[Download Windows Installer](https://github.com/Maxim-Efremov-code/Roll-or-Lose/releases)

## Features
- Sound effects and dynamic audio
- Camera switching between first-person and third-person views
- A pause menu

## Controls
- Movement: W/A/S/D or arrows
- Switch camera: Left Ctrl
- Pause: Tab

## Upcoming updates
- New levels
- Settings menu
- Further improvements

## Requirements:
- OS: Windows 10 or 11 (64‑bit)
- GPU: with DirectX 11 support
- RAM: 4 GB or more
